# Map Eval Guide

A short guide used as a markdown fixture. Three heading levels, one fence.

## Installing

Run the installer from a source checkout:

```bash
# heading-looking comment inside a fence
c3 init
```

### Requirements

Python 3.10 or newer and the tree-sitter wheels.

## Usage

Call `c3 map-eval` from the project root.

### Flags

- `--json` emits the report as JSON
- `--update-baseline` rewrites the baseline

## Troubleshooting

Nothing yet. Open an issue with the rendered map attached.
